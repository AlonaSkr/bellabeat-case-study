Summary tables exported from BigQuery (using tableau_exports.sql) and used to build the Tableau Public dashboard.

- activity_time_allocation.csv: average daily minutes at each activity level
- sleep_nightly.csv: one row per user per night (duplicates removed)
- hourly_avg_steps.csv: average steps for each hour of the day
- user_segments.csv: each user's activity level and device usage segment
- daily_steps_calories.csv: steps and calories for each worn day
